# Практика 4.2 — исправление последнего коммита

В `main.py` записана первая версия программы. Файл `author.py` сначала создан после коммита, а затем добавлен в него командой `git commit --amend`.

Итог: один коммит содержит `.gitignore`, `main.py`, `author.py` и этот README. Сообщение коммита: «Начальный коммит (добавлен файл автора)».
