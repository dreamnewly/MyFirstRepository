# Практика 4.4 — теги версий

Созданы аннотированные теги `v1.0` и `v2.0` на соответствующих коммитах. Для проверки выполнен переход к `v1.0` в состоянии `detached HEAD`; затем работа возвращена в ветку `main`.

- `v1.0` — «Первая стабильная версия», файл показывает «Версия 1.0».
- `v2.0` — «Вторая версия», текущая версия на ветке `main`.
