# Практика 2.5 — навигация и откат истории Git

В упражнении созданы три коммита, проверено состояние `detached HEAD`, создана ветка `old-version`, выполнены `reset --hard`, `restore` и безопасная отмена через `revert`.

## Последовательность

1. В `main.py` добавлялись строки «Версия 1», «Версия 2», «Версия 3» с отдельным коммитом на каждую.
2. По хешу второго коммита выполнен переход назад; ветка `old-version` сохранена от этой точки.
3. В основной ветке `main` команда `git reset --hard HEAD~1` убрала третий коммит из текущей ветки.
4. Для `git restore main.py` строка удалялась вручную, затем файл восстанавливался из коммита.
5. `git revert HEAD --no-edit` создал новый коммит, отменяющий второй; в итоговом файле осталась «Версия 1».
6. В дополнительном упражнении создана ветка `temp`, а указатель `main` перемещён на первый коммит.

`old-version` указывает на второй коммит, `temp` хранит состояние после revert, а `main` после дополнительного шага указывает на первый.
