# Практика 3.3 — cherry-pick и интерактивный rebase

## Выполненные шаги

- Созданы коммиты `v1`, `v2`, `v3`.
- В ветке `feature-logging` добавлен коммит `v4` с сообщением «Лог: программа завершена».
- Коммит `v4` выборочно перенесён в `main` через `git cherry-pick`.
- В интерактивном rebase сообщение первого коммита изменено, `v3` объединён с `v2`, а коммит `v4` сохранён.
- Ветка `feature-logging` оставлена на исходной истории, а `main` содержит переписанную историю с новым коммитом лога.

В инструкции курса есть несоответствие: после cherry-pick предлагается `git rebase -i HEAD~3`, но затем требуется изменить `v1`, объединить `v2` и `v3` и сохранить `v4`. Три последних коммита не включают `v1`, а для четырёх коммитов от корневого коммита используется `git rebase -i --root`. Здесь выполнен rebase через `--root`, чтобы получить описанный результат.
