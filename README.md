# Практика 4.6 — просмотр версии через git describe

История содержит первый коммит, помеченный лёгким тегом `v1.0`, а затем ещё два коммита.

## Результат

С лёгким тегом команда `git describe --tags` выводит `v1.0-2-g<короткий-хеш>`: тег, число коммитов после него и сокращённый хеш текущего коммита.

## Особенность команды

В тексте практики предлагается создать лёгкий тег командой `git tag v1.0`, а затем запустить `git describe`. В обычной конфигурации `git describe` ищет аннотированные теги и не находит такой тег. Для лёгкого тега нужен флаг `--tags`. Если создать аннотированный тег через `git tag -a`, стандартная команда `git describe` сработает без этого флага.
